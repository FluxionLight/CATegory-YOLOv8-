# YOLOv8 实验目录(CATegory)

本目录保留了 YOLOv8 相关实验的**训练数据与训练产物**:

- `datasets/` —— 各版本猫咪检测/分割数据集(详见仓库根目录 README)
- `runs/` —— 历次训练输出(权重 `best.pt`、参数 `args.yaml`、结果图片)

> 说明:本目录最初克隆自部署教程仓库 [DataXujing/YOLOv8](https://github.com/DataXujing/YOLOv8)。
> 因其中框架代码均可在外部直接下载,仓库中已移除,如需运行请自行安装
> `pip install ultralytics`,或另克隆原仓库;随附的预训练权重
> (`yolov8n.pt`、`sam_b.pt` 等)亦需按需自行下载。

完整项目介绍与使用说明见**仓库根目录 [README.md](../../README.md)**。
